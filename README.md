
# 🛒 E-commerce Data Analysis

## 📌 Project Overview

This is an end-to-end **E-commerce Data Analysis project** where raw e-commerce data was cleaned, transformed, analyzed, and visualized using multiple data analytics tools.
Analysis Dashboard built with Excel,Python,Sql and Power BI to analyze sales, profit, orders, products, categories, cities, payment modes and order status.

The project follows a complete data analytics workflow:

**Excel → Python → SQL → Power BI**

The objective is to extract meaningful business insights from e-commerce data and present them through an interactive Power BI dashboard.

---

## 🎯 Business Objectives

The analysis focuses on:

* Understanding overall sales and profit performance
* Analyzing order trends over time
* Identifying top-performing products and categories
* Analyzing city-wise sales performance
* Understanding customer payment preferences
* Analyzing order status
* Identifying profitable product categories
* Creating an interactive dashboard for business reporting

---

## 🔄 Project Workflow

### 1. Data Collection & Initial Inspection — Excel

The raw e-commerce dataset was initially examined using Microsoft Excel.

Activities included:

* Understanding the dataset structure
* Checking columns and data types
* Identifying missing values
* Identifying duplicate records
* Checking inconsistent values
* Reviewing data quality

---

### 2. Data Cleaning & Preprocessing — Python

Python was used for data cleaning and preprocessing.

Main activities included:

* Loading the dataset using Pandas
* Checking missing values
* Handling duplicate records
* Cleaning and standardizing data
* Converting columns to appropriate data types
* Handling inconsistent values
* Preparing the cleaned dataset for analysis

**Libraries Used:**

* Pandas
* NumPy

The cleaned dataset was then prepared for SQL analysis.

---

### 3. Data Analysis — SQL

SQL was used to perform business-oriented analysis on the cleaned e-commerce dataset.

The analysis included:

* Total sales analysis
* Total profit analysis
* Order analysis
* Average order value
* Monthly sales analysis
* Category-wise sales and profit
* Product performance analysis
* City-wise sales analysis
* Payment mode analysis
* Order status analysis
* Top-performing products/categories

SQL helped convert the cleaned data into meaningful business insights.

---

### 4. Dashboard Development — Power BI

Power BI was used to create an interactive dashboard from the analyzed data.

### Dashboard KPIs

* Total Sales
* Total Profit
* Total Orders
* Average Order Value

### Dashboard Analysis

The dashboard provides analysis of:

* Monthly sales trends
* Category performance
* Product performance
* City-wise sales
* Payment modes
* Order status
* Profit performance

Interactive filters/slicers allow users to explore the data dynamically.
